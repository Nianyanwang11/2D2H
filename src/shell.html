Handwriting reading

Inside Claude, handwriting is read through your Claude account. In this app it's read with your own Anthropic API key (make one at console.anthropic.com). Each line read costs a fraction of a cent on your API account.

The key stays on this device and is sent only to Anthropic. Drawing, sketches, 3D graphs and sliders work without it.
